1. Клонировать проект "git clone git@github.com:DontParryMe/test_cpp_app.git"
2. Для успешного запуска тестов в системе должен быть установлен python 3.10.12 или выше
3. Установка python3: sudo apt install python3 python3.12-venv
4. Сделать файл build.sh исполняемым (sudo chmod +x build.sh)  
5. Запустить build.sh (./build.sh) для установки всех необходимых зависиморстей и подготовки виртуального окружения для запуска тестов  
6. Положить в директорию tests файл .env (образец можно посмотреть в .env_example) иначе будут использованы значения по умолчанию (как в условии задания)
7. Сделать файл test.sh исполняемым (sudo chmod +x test.sh)  
8. Запустить тесты (./test.sh)
